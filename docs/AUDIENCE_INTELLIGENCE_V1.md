# Audience Intelligence V1

## Objetivo

Convertir cada pieza en una oportunidad medible para atraer, conversar,
aprender, construir autoridad o detectar afinidad comercial. El sistema no
optimiza únicamente por vistas.

## Cuatro ayudantes virtuales internos

### Editor

Selecciona una historia verificable y define por qué importa para la cultura
digital latinoamericana.

### Anfitrión de comunidad

Elige una pregunta concreta, un formato apropiado por plataforma y una
hipótesis de aprendizaje. Las encuestas nativas que no estén disponibles en
las APIs se preparan para revisión manual; el robot usa como alternativa una
pregunta con opciones estructuradas.

### Analista

Compara conversación, respuestas útiles, compartidos, guardados, retención y
seguidores relevantes. Marca muestras pequeñas y no cambia la estrategia por
sí solo.

### Radar comercial

Identifica señales de patrocinio, pauta, activaciones, servicios creativos y
alianzas. Prepara una ficha y un borrador, pero nunca contacta a terceros sin
aprobación humana.

## Uso de cada red

| Red | Papel principal | Formatos de prueba |
| --- | --- | --- |
| Threads | Conversación y tendencias | texto-pregunta, imagen contextual, video corto |
| Instagram | Descubrimiento, guardados y marca visual | Reel, carrusel, imagen, pregunta en Stories |
| Facebook | Comunidad y monetización | Reel, video, foto-debate, contexto con enlace |
| YouTube | Autoridad y retención | Short, análisis, pregunta de comunidad |

La fábrica rota formatos de forma reproducible por historia. Una regeneración
de la misma noticia conserva el experimento y permite comparar resultados.

## Métricas

- conversación por exposición;
- respuestas calificadas;
- compartidos y republicaciones;
- guardados;
- retención o finalización;
- seguidores relevantes;
- señales comerciales;
- ingresos atribuibles cuando existan.

Cada informe mantiene separadas las métricas de alcance, aprendizaje y negocio.

## Seguridad

- Todo inicia en `draft`.
- Publicación y cambios automáticos de estrategia permanecen apagados.
- Las respuestas y propuestas comerciales requieren aprobación.
- Las encuestas nativas se publican manualmente cuando la API no las soporta.
- Ninguna señal aislada decide el público objetivo; se revisan varias pruebas.
