# Integración del talento virtual con la fábrica V1

## Qué vive en GitHub

GitHub versiona únicamente información pública y reproducible:

- identidad narrativa y función de cada personaje;
- reglas de actuación, formatos y territorios;
- selector que decide quién narra cada historia;
- identificadores abstractos de voz y apariencia;
- divulgación obligatoria de que el personaje es virtual;
- pruebas de privacidad y revisión humana.

## Qué nunca vive en el repositorio público

- fotografías de referencia de José Luis;
- grabaciones originales o muestras de voz;
- modelos biométricos o clonaciones;
- documentos de autorización;
- claves, tokens o rutas de almacenamiento privado.

Los archivos privados se referencian mediante identificadores opacos. La fábrica
puede solicitarlos al renderizador autorizado durante una producción, pero no
los copia al repositorio.

## Flujo

1. El radar encuentra y verifica una historia.
2. El editor calcula territorio, formato y enfoque.
3. El selector de talento elige un personaje habilitado.
4. El guion adopta su criterio, vocabulario y función.
5. El storyboard lo coloca dentro del acontecimiento.
6. El renderizador produce una vista previa.
7. Los controles comprueban fuente, derechos, transparencia e identidad.
8. José Luis revisa el piloto.
9. Publicar continúa deshabilitado en V1.
