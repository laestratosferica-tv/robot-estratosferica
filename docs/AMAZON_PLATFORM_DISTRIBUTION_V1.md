# Distribución Amazon por plataforma V1

## Regla permanente

Una aprobación comercial produce versiones nativas para cada red. El sistema
no copia el mismo enlace y CTA en todas las plataformas.

| Plataforma | Ruta de compra |
|---|---|
| Instagram Reel | CTA al enlace del perfil, sin prometer que el texto es pulsable |
| Instagram Story | Sticker de enlace directo al producto o comparador |
| Facebook | Enlace directo dentro de la publicación |
| Threads | Texto conversacional propio + enlace directo |
| YouTube Short | CTA al enlace del perfil del canal |

## Compuerta previa

La distribución solo queda lista cuando existen las cinco rutas, el producto
visual coincide con el producto real, aparece la divulgación de afiliado y la
protección contra duplicados está activa. Preparar una ruta no reactiva una red:
la publicación sigue requiriendo la compuerta supervisada y sus credenciales.

## Verificación posterior

Registrar un enlace público por plataforma. Si una red no devuelve permalink,
marcar la distribución como parcial y alertar; nunca informar éxito global con
solo Facebook o Instagram publicados.
