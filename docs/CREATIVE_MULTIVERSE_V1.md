# Sistema creativo multiverso

## Regla principal

La Estratosférica mantiene una identidad reconocible, pero no una plantilla
repetida. Voz, mundo, gancho, movimiento y comportamiento del texto deben
cambiar según la historia y no pueden repetirse inmediatamente.

## Reparto de voces

- **Robot explorador:** abre el sistema y vuelve en alertas especiales.
- **Hombre retador:** competencia, análisis, retos y deporte.
- **Mujer estratega:** contexto, descubrimientos, tecnología y estrategia.

Las voces son personajes originales. Está prohibido imitar a personas reales.

## Multimundos

El catálogo inicial incluye arena cyber, raid fantástico, parrilla de carreras,
comando táctico, arcade retro, exploración espacial y supervivencia. Cada mundo
tiene una gramática visual propia y debe relacionarse con el tema.

## Variación controlada

El selector combina cinco dimensiones:

1. Voz.
2. Mundo.
3. Patrón de gancho.
4. Sistema de movimiento.
5. Comportamiento del texto.

El primer piloto usa voz robot. A partir del siguiente contenido se impide
repetir consecutivamente voz, mundo, gancho o movimiento. La pertinencia
editorial siempre tiene prioridad sobre la aleatoriedad.

## Lo que nunca cambia

Fuentes verificadas, texto legible, promesa resuelta, centro sin ruido,
personajes vocales originales y revisión humana antes de publicar.
