# Retorno de autorización de Threads

Página estática usada únicamente como URL de redirección OAuth de Meta.

- No almacena ni transmite el código de autorización.
- No contiene secretos de la aplicación.
- No crea ni publica contenido.
- El código permanece en la URL y en el navegador hasta que el usuario cierre la página.

`https://laestratosferica-tv.github.io/robot-estratosferica/`
