# robot-estratosferica

Motor automatizado de contenido, comunidad y oportunidades comerciales para
La Estratosférica TV.

La estrategia editorial oficial del Sprint Estratosférica 3.0 está en
[`docs/CONTENT_COMMUNITY_MONETIZATION_MATRIX_V1.md`](docs/CONTENT_COMMUNITY_MONETIZATION_MATRIX_V1.md).
Su configuración legible por el robot está en
[`config/content_strategy_v1.json`](config/content_strategy_v1.json).

## Revisión editorial local

La pieza elegida por el selector puede revisarse en un panel local sin
habilitar publicaciones:

```bash
python review_panel.py
```

Consulta el flujo y sus límites de seguridad en
[`docs/HUMAN_REVIEW_PANEL_V1.md`](docs/HUMAN_REVIEW_PANEL_V1.md).
