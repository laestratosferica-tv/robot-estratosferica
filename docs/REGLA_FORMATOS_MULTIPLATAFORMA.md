# Regla de adaptación multiplataforma

Para una idea editorial aprobada, se publica en todas las plataformas compatibles sin reutilizar ciegamente el mismo formato.

- Si la pieza principal es carrusel: Instagram y Threads reciben el carrusel de imágenes; Facebook y YouTube reciben la adaptación en video vertical.
- Si la pieza principal es video: Instagram Reels, Facebook Reels, Threads y YouTube Shorts reciben video vertical adaptado.
- Texto y enlace se reservan para Facebook y Threads cuando el contenido necesita ampliar contexto o llevar tráfico.
- Las Stories se preparan para Instagram y Facebook; los stickers interactivos requieren el flujo nativo supervisado.

Cada manifiesto conserva la misma idea, fuente y objetivo editorial, pero usa el formato nativo más adecuado para la plataforma.
