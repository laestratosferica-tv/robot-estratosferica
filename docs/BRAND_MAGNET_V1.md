# Brand Magnet V1

## Objetivo

Convertir a La Estratosférica en un socio visible para marcas que necesitan
entrar a la cultura gamer latinoamericana con credibilidad, creatividad y
medición.

La propuesta no vende seguidores ni logos sobrepuestos. Vende:

1. comprensión de audiencias;
2. conceptos nativos de gaming;
3. producción multiformato;
4. participación de comunidad;
5. aprendizaje medible.

## Posicionamiento

**La Estratosférica Brand Lab** es la unidad de inteligencia, contenido y
experiencias para marcas.

Promesa:

> No ponemos un logo encima del gaming: encontramos una razón real para que la
> comunidad quiera participar.

## Productos

### Brand Signal

Para una marca que necesita encontrar dónde y cómo entrar.

- mapa de audiencia y tensión;
- territorio creativo;
- concepto de campaña;
- tres piezas prototipo;
- plan de medición.

### Community Quest

Para una marca que necesita participación y aprendizaje.

- reto o pregunta nativa;
- mecánica de participación;
- contenido multiformato;
- clasificación de respuestas;
- informe de aprendizajes.

### Sponsored Multiverse

Para una marca que necesita una serie reconocible.

- concepto narrativo;
- cuatro a ocho piezas;
- voces y mundos visuales variables;
- integración de marca declarada;
- reporte de retención y acciones.

## Sistema de atracción

1. Publicar un `Brand Play` semanal con análisis útil, no adulación.
2. Convertir respuestas de la comunidad en datos agregados.
3. Publicar un `Radar Gamer Colombia` mensual.
4. Mantener una página para marcas con una única llamada a conversar.
5. Construir casos propios antes de afirmar resultados comerciales.
6. Detectar señales de compra entrantes y pasarlas a revisión humana.

## Regla de contenido

Cada `Brand Play` debe responder:

- ¿Qué quería lograr la marca?
- ¿Qué código gamer utilizó?
- ¿Qué valor recibió la comunidad?
- ¿Qué evidencia pública existe?
- ¿Qué mejoraríamos?

No se etiqueta una marca para pedir patrocinio. Se la menciona únicamente
cuando el análisis editorial aporta valor y la relación comercial, si existe,
se declara.

## Embudo comercial

`Brand Play` → visita al perfil → página para marcas → conversación →
diagnóstico → propuesta → piloto → caso de estudio.

## Métricas

- visitas de perfiles empresariales;
- solicitudes de información;
- conversaciones calificadas;
- reuniones;
- propuestas aprobadas;
- ingreso y margen;
- retención, compartidos, guardados y respuestas de cada piloto.

Seguidores y visualizaciones aisladas no prueban intención comercial.

## Seguridad

- Todo concepto especulativo se marca como privado y no oficial.
- No se publica ni contacta una marca sin aprobación de José Luis.
- No se inventan métricas, clientes, testimonios ni alianzas.
- Toda colaboración pagada se declara.
- Los datos de comunidad se presentan agregados y con privacidad.
